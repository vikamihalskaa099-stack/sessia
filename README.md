## Мой вклад в проект

В рамках проекта «Институт мастер-классов» я занималась разработкой веб-сайта, его структурой и оформлением. В процессе работы я использовала HTML для создания структуры страниц и CSS для стилизации элементов и организации внешнего вида сайта.

Основной мой вклад включал:
- Разработку структуры веб-страниц.
- Оформление блоков, карточек и навигационных элементов.
- Подбор и размещение материалов на страницах сайта.
- Организацию файлов и ресурсов проекта.
- Использование Git и GitHub для управления версиями, сохранения изменений и публикации проекта.

## Возникшие трудности

В процессе разработки возникли трудности, связанные с использованием Git и GitHub. В частности, при работе с ветками произошёл конфликт изменений, потребовавший дополнительной проверки файлов и разрешения конфликтов при переносе коммита.

Также возникли проблемы с настройкой удалённого репозитория: первоначально был указан некорректный адрес, из-за чего GitHub отклонял попытку отправки изменений. Для решения проблемы адрес репозитория был исправлен, после чего удалось успешно отправить коммит в ветку `main`.

В результате работы над проектом я получила практический опыт разрешения конфликтов Git, настройки удалённого репозитория и публикации изменений на GitHub.
