## Использование ChatGPT

В процессе разработки проекта ChatGPT использовался в качестве вспомогательного инструмента для решения технических задач:

- **Техническая поддержка:** получение рекомендаций по работе с Git и GitHub.
- **Работа с Git:** устранение проблем при переносе коммитов, настройке удалённого репозитория и публикации изменений.
- **Организация разработки:** получение рекомендаций по последовательности выполнения отдельных этапов работы.

ChatGPT применялся для консультационной поддержки и решения возникающих технических вопросов с целью повышения эффективности разработки и упрощения работы с инструментами управления версиями.
